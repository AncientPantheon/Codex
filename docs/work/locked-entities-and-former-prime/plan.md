# Locked entities, and the Former Codex Prime designation — Plan

Execution plan for `docs/work/locked-entities-and-former-prime/design.md`. Part A
is the "Former Codex Prime" designation; Part B is the "Locked" medallion and the
four live delete-protection bugs behind it. Both land together because both
surface on `OuronetAccountsTab.tsx`.

## Before you start

### The method is not optional

1. **TDD, strictly.** For every task: write the failing test FIRST, run it,
   and WATCH it go RED *for the reason you intended* — not for a typo, a bad
   import, or a missing fixture. Only then write the implementation.
2. **Genuineness check before you report done.** Break the implementation you
   just wrote (invert a condition, return the wrong constant), re-run, and
   confirm the RIGHT tests go RED. Then restore it **byte-exact** and verify:
   `sha256sum` the file before the break and after the restore, and `git diff`
   to confirm the only changes in the working tree are the ones you meant. A
   test that stays green while the implementation is broken is not a test.
3. **Do not edit this file.** `plan.md` is the contract, not a scratchpad.
4. **Do not run state-changing git commands.** No `commit`, `add`, `checkout`,
   `stash`, `reset`, `restore`, `clean`. Read-only git (`status`, `diff`,
   `log`, `show`) is fine.
5. **Stay inside your task's `- files:` list.** If the work genuinely needs a
   file outside it, stop and report that — do not widen your own scope.
6. **Never weaken an existing test to make it pass.** Several tasks below name
   tests that MUST break. Each one is listed with its file, its line range and
   the reason the owner overruled it. Rewrite those deliberately, and record
   the owner's instruction in the test's own comment so the next reader knows
   it was a decision, not a casualty.

      ```ts
      export type EntityLockReason =
        | "codex-prime-account"       // IOuroAccount.isPrime      → CodexPrimeProtectedError

        | "codex-id-half"             // an APOLLO CodexID prime half

        | "prime-chainweb-seed"       // IStoaChainSeed.isPrime    → CodexPrimeSeedProtectedError
        | MasterKeyLockReason         // "master-payment-key" | "master-guard-key", VERBATIM
        | "codex-guard-key"           // isCodexGuard
        | "retired-codex-guard-key"   // wasCodexGuard
        | "duo-pure-prime-key"        // isDuoPurePrime
        | "master-arweave-seed";      // the settled Master ArWeave Seed

      export interface EntityLock {
        readonly reason: EntityLockReason;
        /** One owner-facing sentence — the medallion's tooltip. */
        readonly label: string;
      ```
